# UE5 Physics Playground — Gravity Glove

A physics sandbox built in **Unreal Engine 5.7** (Blueprints only) for a coursework assignment on
physics actors, impulses, radial forces, collision channels and custom collision.

The player carries a **Gravity Glove** that can push, grab, carry, throw and blast physics props.
A generated test level shows how mass and physical materials change their behaviour.

> Status: work in progress. The glove and test level are done; the puzzle chambers are next.

## Controls

| Input | Action |
|---|---|
| WASD / Mouse | Move / aim (over-the-shoulder camera) |
| Left click | **Push** what you aim at (or **throw** what you're holding) |
| Hold right click | **Grab** a prop (≤ 100 kg) and carry it; release to drop |
| Mouse wheel | Move the held prop closer / further |
| Q | **Shockwave** — radial blast around the player (1.5 s cooldown) |
| Space | Jump |

## The Gravity Glove

| Power | How it works |
|---|---|
| Push | Line trace on a custom `GloveTrace` channel → `Add Impulse at Location` (mass matters: 1 kg flies, 120 kg barely moves; off-center hits spin the prop) |
| Grab / carry | `Physics Handle` grabs the prop at its center and current distance; the handle target follows the camera every tick. The held prop ignores the `Pawn` channel so it can't shove or carry the player |
| Throw | Release, then `Add Impulse` with **Vel Change** — everything leaves the hand at the same speed regardless of mass |
| Shockwave | `Radial Force` component placed below the player's feet (props launch up and out), linear falloff, filtered by custom object types so it never affects the player |

All glove logic lives in `BP_GloveCharacter` and is documented with comment bubbles on the nodes.

## Physics setup

**Custom collision channels** (Project Settings → Collision)

| Channel | Kind | Used for |
|---|---|---|
| `PhysProp` | Object | Every movable prop |
| `Metal` | Object | Magnetic props |
| `Barrier` | Object | Energy walls |
| `GloveTrace` | Trace | The glove's aim trace |

**Collision presets:** `PhysProp`, `MetalProp`, `LaserFence` (blocks props, player passes through with an overlap event),
`PawnShield` (blocks the player, props and the glove trace pass through), `PlateTrigger` (overlaps props only).

**Physical materials**

| Material | Friction | Restitution | Combine mode |
|---|---|---|---|
| `PM_Wood` | 0.6 | 0.2 | — |
| `PM_Metal` | 0.4 | 0.05 | — |
| `PM_Rubber` | 0.8 | 0.9 | Restitution: Max |
| `PM_Ice` | 0.02 | 0.1 | Friction: Min |

**Props** — one base Blueprint (`BP_PhysProp`); children only override mass and physical material, applied in the Construction Script.

| Prop | Mass | Material |
|---|---|---|
| Wood crate | 20 kg | Wood |
| Metal crate | 60 kg | Metal (`MetalProp` preset) |
| Steel crate | 120 kg — too heavy to grab | Metal |
| Bouncy ball | 5 kg | Rubber |
| Balloon | 1 kg | Rubber, high damping + upward force |

## Test level — `L_PhysicsPlayground`

Stations: prop lineup with mass labels, domino run into a crate pyramid, **slide test** (same steel crate on
ice / metal / wood / rubber ramps at 25° — only ice slides), **drop test** (same crate dropped on four
material pads — only rubber bounces), ball pit with jump pad, balloon garden.

The level is generated by an editor Python script and can be rebuilt any time:

```
Output Log → switch "Cmd" to "Python" →
exec(open(unreal.Paths.project_dir() + "Scripts/build_physics_playground.py").read())
```

## Opening the project

1. Install **Unreal Engine 5.7**.
2. Clone with Git LFS installed (`git lfs install`), then open `Physics_PG_Ass_02.uproject`.
3. Open `Content/Physics_PlayGround/Maps/L_PhysicsPlayground` and press Play.
